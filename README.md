# Find Roommate Form

It is a responsive roommate matching form built using HTML and CSS that helps users find a roommate by filling out personal information and preferences.

## Features

- User information collection:
  - Name
  - Surname
  - Age
  - Gender
  - City
  - Preferred district
  - Personal bio
  - Email
  - Phone number

- Form validation using HTML attributes:
  - Required fields
  - Email validation
  - Age range restrictions

- Responsive layout:
  - Two-column layout for larger screens
  - Single-column layout for mobile devices

- Mobile-friendly single-column layout

- Custom focus states for better accessibility

- Clean and modern design using CSS

## Tech Stack

- HTML5
- CSS3
- Google Fonts (Roboto)

## Concepts Practiced

- Semantic HTML structure
- HTML forms and input types
- Labels and accessibility best practices
- Radio buttons and fieldsets
- CSS Grid and Flexbox layouts
- Responsive design with media queries
- Form styling and user interaction states

## Learning Outcomes

Through this project, I practiced building a complete responsive form from scratch and improved my understanding of:

- Creating accessible HTML forms
- Organizing page structure with semantic elements
- Designing responsive layouts
- Using CSS Grid and Flexbox effectively
